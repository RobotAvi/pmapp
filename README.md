## 🚀 Особенности

### ✅ Реализованные функции
- **Управление проектами** - создание, редактирование, удаление проектов
- **Управление аккаунтами** - работа с клиентскими аккаунтами
- **Статусы проектов** - отслеживание состояния проектов
- **Responsive UI** - адаптивный интерфейс на Bootstrap 5
- **База данных** - структурированное хранение данных с Prisma ORM

### 🔄 В разработке
- **Управление сотрудниками** - полный HR функционал
- **Система навыков** - управление компетенциями команды
- **Планирование ресурсов** - оптимизация загрузки сотрудников
- **Аналитика и отчеты** - визуализация данных проектов
- **Календарь проектов** - временные шкалы и дедлайны
- **Система уведомлений** - автоматические напоминания

## 🚀 Быстрый старт

### Предварительные требования
- Node.js (версия 18 или выше)
- npm или yarn

### Установка

1. **Клонируйте репозиторий**
   ```bash
   git clone <repository-url>
   cd pmapp
   ```

2. **Установите зависимости**
   ```bash
   npm install
   ```

3. **Настройте базу данных**
   ```bash
   # Создайте .env файл (уже создан)
   # DATABASE_URL="file:./dev.db"
   
   # Примените миграции
   npx prisma migrate dev --name init
   
   # Заполните тестовыми данными
   npx prisma db seed
   ```

4. **Запустите приложение**
   ```bash
   npm run dev
   ```

5. **Откройте в браузере**
   ```
   http://localhost:3000
   ```

### Дополнительные команды

```bash
# Просмотр базы данных
npx prisma studio

# Сборка для продакшена
npm run build

# Запуск продакшен версии
npm start

# Линтинг кода
npm run lint
```

## 📝 API Документация

### Проекты
- `GET /api/projectsApi` - получить все проекты
- `POST /api/projectsApi` - создать новый проект
- `PUT /api/projectsApi?id={id}` - обновить проект
- `DELETE /api/projectsApi?id={id}` - удалить проект

### Аккаунты
- `GET /api/accountsApi` - получить все аккаунты
- `POST /api/accountsApi` - создать новый аккаунт
- `PUT /api/accountsApi?id={id}` - обновить аккаунт
- `DELETE /api/accountsApi?id={id}` - удалить аккаунт

## 🔧 CI/CD

### GitHub Actions

Проект настроен с GitHub Actions для автоматической проверки качества кода:

#### Workflows

1. **Test Build** (`.github/workflows/test.yml`)
   - Запускается при push в `main` и `develop` ветки
   - Выполняет:
     - Установку зависимостей
     - Проверку кода линтером
     - Запуск unit тестов
     - Генерацию отчета о покрытии
     - Сборку проекта
     - Загрузку отчетов в Codecov

2. **Security Check** (`.github/workflows/security.yml`)
   - Запускается при push и еженедельно
   - Проверяет уязвимости в зависимостях
   - Анализирует устаревшие пакеты

#### Настройка

1. **Codecov** (опционально):
   - Зарегистрируйтесь на [codecov.io](https://codecov.io)
   - Подключите ваш репозиторий
   - Получайте детальные отчеты о покрытии кода

2. **GitHub Actions Artifacts**:
   - Отчеты автоматически сохраняются в GitHub Actions
   - Доступны в разделе "Actions" вашего репозитория
   - Хранятся 30 дней

#### Поддерживаемые версии Node.js
- 18.x
- 20.x

### Локальное тестирование CI/CD

Для проверки того, что ваш код пройдет CI/CD:

```bash
# Проверка линтера
npm run lint

# Запуск тестов
npm run test
```
